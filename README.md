

# Zen Reading App React Frontend

This project is developed and maintained by Zlat Antonio Florian.

## Project Overview

Zen is a platform designed specifically for amateur writers to share their stories, receive constructive feedback, and enhance their writing skills. This React-based frontend, powered by Vite, serves as the user interface for the Zen application.

### Technology Stack
- **Frontend:** React + Vite
- **Backend:** Node.js
- **Database:** PostgreSQL

## Objectives
- Deliver an intuitive and engaging user experience for amateur writers
- Facilitate community-driven feedback and interaction
- Support personal growth and skill development in creative writing

## Vite/React Information
This project leverages Vite for rapid development and hot module replacement (HMR), along with recommended ESLint rules for code quality. For further details:
- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) utilizes [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) utilizes [SWC](https://swc.rs/) for Fast Refresh

## React Compiler
The React Compiler is not enabled in this template. To enable it, refer to the [official documentation](https://react.dev/learn/react-compiler/installation).

## ESLint Configuration
For production environments, it is recommended to use TypeScript with type-aware lint rules. Refer to the [TypeScript template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for guidance on integrating TypeScript and [`typescript-eslint`](https://typescript-eslint.io).
